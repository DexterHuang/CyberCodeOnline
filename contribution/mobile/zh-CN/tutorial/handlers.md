# 导师

## 导师的职责是什么？
导师是帮助符合条件的学员完成前期成长的资深玩家。达到 `200` 级后，学员可以从你的个人资料中选择你作为导师。你不能自行给自己分配学员。

## 谁可以选择我作为导师？
- 学员等级必须在 `15` 至 `30` 级之间。
- 学员账号的注册时间不得超过 `60` 天。
- 你的等级必须至少为 `200`。
- 选择时和达到 `50` 级时，系统都会检查学员的小号及其他资格条件。奖励不保证发放。
- 学员和导师都不能拥有其他账号。若任一方有其他账号，该导师关系会自动失去资格，且不会发放导师奖励或导师点数。

## 学员如何选择我？
1. 学员打开你的个人资料。
2. 选择 **设为导师**。
3. 阅读无法更改选择的警告，勾选确认框，然后选择 **永久选定**。

每名学员只能选择一位导师。选择会立即生效且永久有效，无需你接受。

## 如何管理我的学员？
分配给你的学员会列在 **个人资料 → 资产** 中，并且只有你能看到。你不能解除他们的导师关系。达到 `50` 级之前，学员可以从自己的 **个人资料 → 资产** 中结束关系。导师关系将永久关闭，学员以后再也无法选择其他导师。

所选导师默认显示在学员的 **个人资料 → 资产** 中，但学员可以在 **设置** 中将其隐藏。你的 **已指导学员数** 始终公开。

## 我什么时候能获得奖励？
当符合条件的学员达到 `50` 级时，系统会再次检查导师关系。若通过所有检查，这次指导会计入你的公开成绩，你也会获得当前的导师奖励。当前奖励可在 **个人资料 → 资产** 中查看。
