# Reclamation Depot

Th' **Reclamation Depot** be a community item donation system. Its main purpose be t' let scallywags get rid o' extra items they don't need while feedin' th' shared reward pool. Sometimes ye may also earn vouchers along th' way, matey.

## Requirements

- There be a level requirement t' donate items.
- Redeemin' vouchers unlocks earlier than donatin'.
- Check th' game UI if ye be nah sure whether yer character can use it yet.

## How Donatin' Works

When ye donate items, they be removed from yer inventory an' added t' th' shared reward pool.

Only certain items can be donated, an' some o' them must be donated in fixed stack sizes. Th' game will show ye what can be selected.

Sometimes ye'll receive a voucher fer donatin' items. Th' type o' voucher depends on th' item donated.
Ye can then use th' voucher t' redeem items from th' shared pool.

Donations be permanent an' can nah be undone.

## Voucher Types

There be two voucher tiers in th' Reclamation Depot.

### Low Reclamation Voucher

Low vouchers be usually earned from more common or lower-value donation items.

### High Reclamation Voucher

High vouchers be usually earned from more valuable donation items.

## How Redeemin' Works

Ye can spend a voucher t' redeem a random reward from thar voucher tier.

Rewards be drawn from th' current shared pool, so what ye get depends on what scallywags 'ave donated. Items wit' more stock in th' pool be more likely t' be redeemed. Th' item counts shown in th' depot be approximate 'n update from time t' time.
